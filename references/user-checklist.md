# Steps only the site owner can do

Fill in the brackets and hand this to the user at the end of phase 6. Keep it short and in order.

## Accounts
- [ ] Domain + hosting with SSL; WordPress installed; Hello Elementor + Elementor + Rank Math installed.
- [ ] Amazon Associates account for the right store; tracking ID entered in [engine plugin] → Settings.
- [ ] (After qualifying sales) Amazon API keys entered in Settings — never in chat.
- [ ] Optional AI helper key (e.g. Gemini free tier) entered in Settings.
- [ ] Google Search Console property verified; Google Site Kit connected.

## Uploads (Plugins → Add New → Upload / Appearance → Themes → Upload)
- [ ] [child theme zip] → activate.
- [ ] [engine plugin zip] → activate → Settings.
- [ ] [SEO plugin zip] → activate → Settings tab (tracking ID, post types) → apply Rank Math setup.
- [ ] Clear the cache after each upload.

## Content the owner must supply or approve
- [ ] Logo (square ≥112 px), social image 1200×630, site icon.
- [ ] Real photos where possible; featured image on every post.
- [ ] Approve product picks, verdict lines and any opinion text.
- [ ] Real expert reviewer (name + credentials) — or leave the review fields empty.
- [ ] Newsletter provider connected, or remove the form.

## Google
- [ ] Submit `/sitemap_index.xml`; remove old sitemap entries that redirect; (move) submit `/old-urls.xml` for ~45 days.
- [ ] Request indexing for home + main hubs.
- [ ] Check Rich Results Test on one page of each type.

## Ongoing
- [ ] Weekly: SEO plugin → Monitor (404s, Fix), Search Console coverage.
- [ ] Monthly: click-check product links; Tools → Amazon product health.
- [ ] Every 6 months: Reviews tab → update due pages.
